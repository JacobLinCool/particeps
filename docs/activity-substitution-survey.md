# 時段活動與裝置替代問卷

本問卷補足研究手機遙測無法觀察的部分：參與者是否使用其他裝置，以及運動、面對面聊天、戶外活動等手機以外的活動，並詢問手機網路速度對日常活動的主觀影響。手機使用量下降本身無法區分這些情形。

七題版同步於兩份五天範本及[正式研究來源](../researcher-tools/studies/phone-usage-five-day.json)。正式設定 `phone-usage-five-day-20261011-r2` 重新簽署後，經[參與者頁](https://jacoblincool.github.io/particeps/participant/)的固定 `study.partcfg` 入口提供。已加入的研究不會自動更新；原六題資料仍依原配置解讀。後續更新與驗證方式見[發布流程](study-publication.md)。

本稿保留原排程：研究第 3–5 個當地日期的 17:00 邀請填寫，回顧當日 12:00–17:00，觸發後可填寫六小時。未新增晚間問卷或第 1–2 天的邀請。

## 七題內容

| 題目 | 填答形式與目的 |
| --- | --- |
| 除了操作這支手機，還做過哪些活動？ | 可略過複選：運動、面對面互動、戶外活動、工作學習、紙本閱讀、家務照顧／辦事、通勤、用餐、休息睡覺、其他。同時使用其他裝置也可以勾選。 |
| 沒有使用螢幕裝置的時間合計大約多久？ | 單選：沒有、有但未滿 30 分鐘、30 分鐘至未滿 1 小時、1–未滿 2 小時、2–未滿 4 小時、4–5 小時、不記得／無法估計。 |
| 使用過哪些這支手機以外的裝置？ | 可略過複選：電腦、平板、其他手機、電視、遊戲機、穿戴裝置、其他。 |
| 在上述 12:00–17:00 時段，您是否曾將原本正在或打算在這支手機上進行的活動，改到其他裝置上進行？（包含玩遊戲） | 必填單選：是，至少一次／否／不記得或不確定。 |
| 是否把原本正在或打算在這支手機上做的事改成無螢幕活動？ | 單選：有至少一次、沒有、不記得／不確定。 |
| 原本要做什麼、後來改用什麼裝置或改做什麼活動，以及原因？ | 可略過文字補充，上限 1,000 UTF-16 code units；不預列網路變慢等原因。 |
| 您覺得上述 12:00–17:00 時段的手機網路速度，對您這段時間的日常活動影響程度如何？ | 必填單選：非常大／大／中等／小／完全沒有影響／不確定。 |

「這支手機」明確指安裝研究 App 的手機。無螢幕時間題涵蓋手機、平板、電腦、電視、遊戲機等螢幕裝置。活動題則不限於完全無裝置的情境，例如使用電腦工作仍能勾選工作學習；不能把第一題的所有答案直接當作無螢幕活動。

四題單選提供不確定選項；活動與裝置複選題不加入可與具體選項矛盾並選的「沒有」選項。現有問卷引擎沒有跨題跳題或一致性驗證，因此所有七題都會顯示，兩題複選及文字題可略過。

不加入第八題「限速後手機使用時間增加多少」，也不新增「等待時段結束後再使用手機的意願」題。限速前、中、後的手機使用時間以 `usage_events.v1` 的來源事件分析；資料缺口、截尾與未配對事件須另行標記，不能當成零使用。第七題補充主觀影響，不重複要求參與者估算客觀使用分鐘數。

## 分析對應

| Question ID | 主要解讀 |
| --- | --- |
| `off-phone-activities` | 實際發生的活動類型，可重疊；戶外運動可同時勾戶外與運動。選項數不是活動次數，也不能相加成互斥的時間分配。 |
| `screen-free-time` | 0–5 小時的自陳時間區間。`none` 才表示明確回答沒有；`unsure` 是未知。不要把區間中點當成量得的分鐘數。 |
| `other-devices` | 回想起來的其他裝置種類；不代表那些裝置上實際執行的 App 或使用時長。 |
| `device-substitution` | 主要裝置替代指標，不能僅由 `other-devices` 有勾選推論替代。 |
| `non-screen-substitution` | 主要無螢幕活動轉移指標。可與裝置替代同時發生，不是互斥答案。 |
| `activity-context` | 補充原活動、後續活動／裝置及自述原因；空白不代表沒有原因。 |
| `perceived-daily-impact` | 主觀影響程度的序位答案；不代表影響是正面或負面，也不是客觀使用時間。`unsure` 為未知，不可當作沒有影響。 |

七題版中 `device-substitution` 的建議編碼：

| Answer ID | 曾替代這支手機 | 解讀 |
| --- | --- | --- |
| `yes` | 是，至少一次 | 自述曾把該活動改到其他裝置；不表示必然由限速造成 |
| `none` | 否 | 可能未用其他裝置，也可能用過但未替代；裝置種類另由第三題記錄 |
| `unsure` | 未知 | 不記得或不能確定，不能併入 `none` |

未回答／空白複選不等於「沒有活動」或「沒有裝置」。勾選其他裝置、但第四題回答 `none`，是合理的「有使用但未替代」，不能標成矛盾；第四題回答 `yes` 而未勾裝置種類時，保留替代答案並將裝置種類視為缺漏。

已發布六題版的第四題使用不同選項。回收資料須依配置身分及原始題目／選項解讀，保留版本，不將新舊選項直接視為相同答案；舊資料沒有第七題，不得補成「完全沒有影響」。

問卷回覆應依介入 invocation、參與者及當日回顧時段配對手機遙測，保留實際邀請／提交時間。不要把填答當下的日期直接當成回顧日期，因為邀請延遲後的六小時可填寫期限可能跨過午夜。問卷說明以最近一次已結束的 12:00–17:00 為準，並提醒跨午夜填答時回顧前一天，避免題目中的「今天」改變指涉。此說明依目前 17:00–23:59 邀請與六小時有效期設計；若改成更晚補發或延長跨日有效期，應改為顯示明確目標日期。

## 推論界線

這些是參與者的自陳資料，並非其他裝置的被動追蹤，也不是已驗證的標準量表。問卷分開詢問實際活動與自陳轉移，不預設轉移是研究限速造成；原因採開放填答。原始研究僅在第 3–5 天提供此問卷，沒有第 1–2 天相同問卷作為直接對照，因此不能單憑答卷把所有轉移歸因於限速。
