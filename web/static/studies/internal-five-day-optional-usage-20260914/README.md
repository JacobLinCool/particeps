# 五天手機使用研究：App 使用事件選用版

這份設定供團隊內部試跑，將 `usage_events.v1` 改為 `required: false`。參與者未授予「使用情況存取權」時也能完成設定並開始研究；授權後才會收集 App 使用事件。

其餘六項收集器仍為必要：陀螺儀、網路狀態、網路吞吐量、螢幕狀態、時間背景與 VPN 狀態。五天排程、每日陀螺儀時段、限速設定、問卷、儲存與匯出加密金鑰沿用原研究。

## RC13 的執行限制

「選用」允許在開始研究時略過無法啟用的 App 使用事件來源。若來源已成功開始收集，之後才撤銷授權或發生來源錯誤，RC13 仍可能安全暫停整份研究；此設定沒有修改 App 的執行中失敗處理。

## 驗證

已使用研究者 CLI 驗證設定格式、原研究簽章公鑰及 RC13（versionCode 40）的匯入相容性，並以 Python 獨立驗證 Ed25519 簽章、檔案 SHA-256 與設定內容一致。與舊版相比，只變更 App 使用事件的必要性、設定識別碼、簽發時間及同意文件版本與說明；舊版已發出的檔案逐位元組相同。
